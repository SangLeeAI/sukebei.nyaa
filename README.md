# Nyaa

sukebei.nyaa.si 공개 검색과 같은 검색어로, 선택한 시작일부터 오늘까지 목록을 보여주는 로컬 웹 앱입니다. Vite + React + TypeScript.

검색 요청은 브라우저가 사이트를 직접 치지 않고, 이 컴퓨터의 Vite 개발 서버가 공개 검색 페이지를 순서대로 가져와 JSON으로 돌려줍니다. 계정은 없고, 검색어별 마지막 다운로드 기록만 로컬 SQLite에 남깁니다.

## 로컬에서 실행

Node.js 20 이상이 필요합니다.

```bash
cd /home/slime/projects/nyaa
npm install
npm run dev
```

개발 서버는 `http://127.0.0.1:48621` 에서 켜지고, 브라우저가 자동으로 열립니다. 상단 검색창에 검색어를 넣고 검색하세요.

끝내려면 터미널에서 `Ctrl+C`를 누르세요.

## 검색이 하는 일

1. `/api/search?q=...&since=YYYY-MM-DD` 가 sukebei 공개 검색(`f=0`, `c=0_0`, 최신순)을 1페이지부터 요청합니다.
2. 제목, 날짜, 용량, 시드/리치, 분류, 마그넷·토렌트 링크를 읽습니다.
3. 항목이 시작일보다 오래되면 멈추고, 페이지가 더 없으면 그 전에 멈춥니다. 시작일 기본값은 오늘부터 30일 전입니다.
4. 페이지 사이에 짧은 간격을 두어 공개 페이지를 과하게 두드리지 않습니다.
5. 목록이 오면 `/api/translate`가 제목(한글이 아닌 분류 포함)을 한국어로 옮깁니다. 키 없는 무료 번역을 이 컴퓨터에서 호출하고, 실패하면 원문을 그대로 둡니다. 원문은 제목 아래와 툴팁에 남습니다.
6. 공개 HTML에서 `tr.success`(신뢰 토렌트)이면 제목·원문을 `#5cb85c`로 표시합니다. 사이트의 연두색 success 행과 같은 Bootstrap 초록입니다.
7. 상단 **시드** 칸은 최소 시드 수입니다. 기본값·빈 칸·잘못된 값은 3이고, 가져온 목록 가운데 그 이상만 보여 줍니다.
8. 상단 **시작일**은 검색 범위의 첫날입니다. 날짜를 바꾸면 그 날 0시부터 오늘까지 다시 가져옵니다.
9. 각 결과 제목 옆에 체크박스가 있습니다. 기본은 선택되지 않습니다. **전체 선택** / **선택 해제**로 지금 보이는 목록을 다루고, **선택한 토렌트 받기**는 체크한 글만 받습니다. 선택이 없으면 버튼이 비활성입니다.
10. 받기는 sukebei의 `/download/{id}.torrent` 과 같은 토렌트 파일 링크를 Vite 프록시가 대신 요청합니다. 마그넷은 쓰지 않습니다. 파일이 없으면 그 항목만 건너뜁니다. 한 개면 브라우저가 `.torrent` 하나를 저장합니다. 여러 개면 폴더 선택 창이 한 번만 뜨고, 고른 폴더에 `.torrent`을 각각 씁니다. zip은 만들지 않고, 파일마다 저장 창을 띄우지 않습니다. 폴더 선택을 지원하지 않으면 확인 한 번 뒤에 이 컴퓨터의 다운로드 폴더에 저장합니다.
11. 체크한 토렌트를 성공적으로 받으면, 그중 **가장 최근 글**의 날짜와 제목(한국어·원문)을 현재 검색어 키로 SQLite(`data/nyaa.sqlite`)에 저장합니다. 같은 검색어로 다시 찾으면 그 기록이 나오고, **이 날짜를 시작일로**를 누르면 시작일 칸에 그 글의 날짜가 들어갑니다. 기록이 없으면 시작일은 오늘부터 30일 전입니다.
12. 받기가 끝나면 qBittorrent에 넣을지 묻습니다. **추가**는 이 컴퓨터 Web UI(`127.0.0.1:8080`, 로컬 인증 없음)로 `.torrent`을 넣습니다. **나중에**는 파일을 그대로 두고 `pending_qbittorrent` 테이블에 남깁니다. 상단 **미추가 파일 다운로드**에서 골라 다시 넣을 수 있습니다. 넣은 항목은 목록에서 빠집니다.

## 스크립트

- `npm run dev` — 개발 서버 (127.0.0.1:48621, 브라우저 자동 실행)
- `npm run build` — 프로덕션 빌드
- `npm run preview` — 빌드 결과 미리보기
