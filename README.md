# Nyaa

sukebei.nyaa.si 공개 검색과 같은 검색어로, 최근 약 30일 목록을 보여주는 로컬 웹 앱입니다. Vite + React + TypeScript.

검색 요청은 브라우저가 사이트를 직접 치지 않고, 이 컴퓨터의 Vite 개발 서버가 공개 검색 페이지를 순서대로 가져와 JSON으로 돌려줍니다. 계정·데이터베이스는 없습니다.

## 로컬에서 실행

Node.js 20 이상이 필요합니다.

```bash
cd /home/slime/projects/nyaa
npm install
npm run dev
```

개발 서버는 `http://127.0.0.1:48621` 에서 켜지고, 브라우저가 자동으로 열립니다. 상단 검색창에 검색어를 넣고 검색하세요.

끝내려면 터미널에서 `Ctrl+C`를 누르세요.

## 검색이 하는 일

1. `/api/search?q=...` 가 sukebei 공개 검색(`f=0`, `c=0_0`, 최신순)을 1페이지부터 요청합니다.
2. 제목, 날짜, 용량, 시드/리치, 분류, 마그넷·토렌트 링크를 읽습니다.
3. 항목이 약 30일보다 오래되면 멈추고, 페이지가 더 없으면 그 전에 멈춥니다.
4. 페이지 사이에 짧은 간격을 두어 공개 페이지를 과하게 두드리지 않습니다.
5. 목록이 오면 `/api/translate`가 제목(한글이 아닌 분류 포함)을 한국어로 옮깁니다. 키 없는 무료 번역을 이 컴퓨터에서 호출하고, 실패하면 원문을 그대로 둡니다. 원문은 제목 아래와 툴팁에 남습니다.

## 스크립트

- `npm run dev` — 개발 서버 (127.0.0.1:48621, 브라우저 자동 실행)
- `npm run build` — 프로덕션 빌드
- `npm run preview` — 빌드 결과 미리보기
